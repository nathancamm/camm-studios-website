# Camm Studios Website

One Astro repository builds three independent static sites:

- `www.cammstudios.com` for the company
- `bronzed.cammstudios.com` for Bronzed
- `stellar.cammstudios.com` for Stellar

## Local development

```bash
npm install
npm run dev
npm run dev:bronzed
npm run dev:stellar
```

The development commands use Astro's default port. Run one target at a time or pass a different port.

## Design

All three sites share a video background, Helvetica typography, and liquid-glass panels and footers. Astro keeps page content static; React handles video controls and the Motion footer. Tailwind CSS v4 supplies the shared utility styles without resetting existing page typography.

The supplied CloudFront video and Helvetica font are loaded remotely. Reduced-motion visitors receive a still background, playback can be paused, and unavailable media falls back to a dark background. Decorative artwork uses an SVG alpha filter to remove its white matte without modifying source files.

## Verification

```bash
npm run check:all
npm test
```

`npm test` runs the unit tests, builds all targets and verifies routes, canonical URLs, product links, legal pages and redirects.

## Sunburn calculator

`bronzed.cammstudios.com/sunburn-calculator/` ports the Bronzed app's estimate to `src/shared/lib/burn-time.ts`. The source is `Shared/BronzedCalculator.swift` and `Shared/SkinType.swift` in the `tan` repository. Keep the constants and order of operations identical, and update the port and `tests/burn-time.test.ts` whenever the app's maths changes. The web version has no daylight cap, because it has no location or sunset time.

## Deployment

The company site and Bronzed run on Cloudflare as assets-only Workers, configured in `cloudflare.config.ts`. The `cammstudios.com` zone is on Cloudflare, and each Worker's custom domain owns its DNS record.

| Site | Worker | Domain | Deploy |
| --- | --- | --- | --- |
| Company | `camm-studios-site` | `www.cammstudios.com` | `npm run deploy:company` |
| Bronzed | `bronzed-site` | `bronzed.cammstudios.com` | `npm run deploy:bronzed` |

Run `cf auth login` once per machine. Each deploy script builds its target, then runs `cf deploy` with `SITE_TARGET` set.

`cammstudios.com` has a proxied placeholder record and a zone redirect rule that sends every request to `https://www.cammstudios.com` with the same path and query (301).

Stellar is not deployed. `stellar.cammstudios.com` does not exist yet, so the company site links Stellar to its App Store page. Deploying it needs its own entry in `cloudflare.config.ts` and a review of its copy against the app.

## Legal pages

The apps link to privacy policies, terms and support pages on the company site, such as `https://cammstudios.com/apps/bronzed/privacy.html` and `/apps/mp3-converter/privacy`. Those documents live unchanged in `legacy/company/`, and the company build copies them into its output byte for byte. A file there may not share a path with a generated page.

Until new legal documents are approved, the sites point at those versions:

- Company: `/privacy/` and `/terms/` redirect to `/privacy-policy/` and `/terms-of-service/`.
- Bronzed: `/privacy/` and `/terms/` redirect to the company site's `/apps/bronzed/` documents.

Both redirect lists are generated by `[redirects].ts` in each target's pages folder. The Astro privacy and terms pages are drafts and are not reachable while those redirects exist.
